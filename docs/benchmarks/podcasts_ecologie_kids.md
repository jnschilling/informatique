# Benchmark — Podcasts français écologie/nature pour CM1-CM2

> Mission Huginn — 2026-05-07
> Cible : inspirer le projet TP2 Podcast Écologie (CM1 + CM2, École Saint-Anne)
> Critères : durée 2-10 min, ton accessible 9-11 ans, structure claire, bruitages/musique

---

## Top 7 sélectionnés

### 🏆 1. Curieux de sciences (Bayard + MNHN)
- **URL** : https://www.mnhn.fr/fr/curieux-de-sciences
- **Durée** : ~10 min · 7-12 ans
- **Format** : Q&R d'enfants à des chercheurs
- **À noter** : **co-conçu avec une classe de CM2** !
- **Pourquoi inspirant** : référence absolue — les questions viennent vraiment des enfants. Modèle 1:1 pour ce qu'on fait.

### 🌳 2. Radio Bambou (Reporterre)
- **URL** : https://reporterre.net/Radio-Bambou
- **Durée** : ~10 min · bimensuel · 8-12 ans
- **Format** : reportage de terrain avec mascotte (Bambou, panda roux)
- **Thèmes** : ruchers urbains, pollinisation, conservation
- **Pourquoi inspirant** : 100% écolo, format reportage directement répliquable par les équipes.

### 🦊 3. Bestioles (France Inter + MNHN)
- **URL** : https://www.radiofrance.fr/franceinter/podcasts/bestioles
- **Durée** : 5-10 min · 70 épisodes
- **Format** : conte humoristique, un animal par épisode
- **Voix** : Denis Cheissoux + Brigitte Lecordier (Sangoku !)
- **Pourquoi inspirant** : durée idéale 5 min, biodiversité ludique, voix animées — modèle parfait pour l'équipe CM1 "animaux".

### 📰 4. Allo, 1jour1actu ? (Milan Presse)
- **URL** : https://podcast.ausha.co/allo-1jour1actu
- **Durée** : 5 min hebdo · 8-12 ans
- **Format** : journaliste + spécialiste répondent à 1 question d'actu
- **Pourquoi inspirant** : durée cible idéale (5 min), Q&R clair — modèle parfait pour les thèmes en question (CM2 "Comment ne pas gaspiller ?").

### 🎙️ 5. Salut l'info ! (franceinfo + Astrapi)
- **URL** : https://www.franceinfo.fr/replay-radio/salut-l-info/
- **Durée** : ~15 min hebdo · 7-11 ans
- **Format** : 3 sujets d'actu + espace de parole enfants
- **Pourquoi inspirant** : voix d'enfants intégrées, structure claire — directement transposable.

### 📖 6. Les Odyssées (France Inter)
- **URL** : https://www.radiofrance.fr/franceinter/podcasts/les-odyssees
- **Durée** : 12-15 min · 7-12 ans
- **Format** : storytelling narratif (Laure Grandbesançon)
- **Épisodes éco** : Rachel Carson, Anita Conti, Jane Goodall
- **Pourquoi inspirant** : narration immersive, bruitages, dramaturgie parfaite. Plus long mais très inspirant pour la qualité narrative.

### 🌊 7. OLMA (France Inter + Cité des Sciences)
- **URL** : https://www.radiofrance.fr/franceinter/podcasts/olma
- **Durée** : ~10 min · 8-12 ans
- **Format** : fiction sonore (voilier au Spitzberg)
- **Pourquoi inspirant** : fiction + science réelle, immersion sonore — pour montrer ce que le bruitage peut créer.
