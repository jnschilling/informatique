# Évaluation Continue

- **Formatifs** : Quiz en ligne ([Kahoot](/docs/activites/kahoot)), portfolios numériques. Nouveauté 2026-2027 : les questions d'histoire programmées par les CM2 dans le TP1 alimentent nos quiz de révision !
- **Sommatifs** : Par TP (grille : compétences de base 40 %, créativité 30 %, collaboration 30 %).
- **Attendus de fin d'année, par niveau** :
  - **CM1** (nouveau programme) : découvrir l'algorithme via des applications visuelles et ludiques ; donner des instructions à un robot ou un personnage pour qu'il se déplace ; collaborer avec les outils numériques.
  - **CM2** (programme 2020/2023) : concevoir un programme simple répondant à un cahier des charges ; tester et modifier un programme par essai-erreur.
