# Les bases (Septembre - Octobre) 🧰

Avant les grands projets, on apprend trois gestes qui servent toute l'année.

| Le geste | Ce qu'on fait | Avec quoi | Combien de temps |
| -------- | ------------- | --------- | ---------------- |
| 📁 **Ranger et sauvegarder** | Créer ton dossier, donner un nom clair à tes fichiers | L'explorateur de fichiers, OneDrive | 3 séances |
| 🔎 **Chercher sur internet** | Utiliser un moteur de recherche protégé, dire d'où vient une information | Qwant Junior, des images libres | 2 séances |
| 🤖 **Utiliser une IA** | Poser une question simple pour trouver des idées, puis **vérifier** la réponse : une IA peut se tromper | Une IA pour l'école, toujours avec un adulte | 1 séance |
