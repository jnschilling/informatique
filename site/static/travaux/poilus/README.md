# Dépôt des fiches Poilus (modéré par l'enseignant)

Circuit : l'élève exporte sa fiche .odt en **PDF** (Fichier → Exporter au format PDF)
→ dépôt dans le dossier OneDrive/ENT de la classe → relecture par l'enseignant
→ copie **ici** → `poetry run python generer_galerie_poilus.py` → commit → push.

## Convention de nommage

`prenom_nom-du-poilu.pdf` — exemple : `lea_martin-jean.pdf`
(prénom de l'élève seul, jamais le nom de famille de l'élève — site public)

## Garde-fous avant toute publication

- [ ] Autorisation parentale écrite (publication de travaux d'élèves)
- [ ] Prénom d'élève uniquement dans le PDF (pas de nom, pas de photo d'élève)
- [ ] Relecture du contenu (le commit de l'enseignant EST la modération)
